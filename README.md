# ferrouslion.com

Public homepage for Ferrous Lion. Served by GitHub Pages at [ferrouslion.com](https://ferrouslion.com).

YouTube videos refresh automatically from the channel feed.

The Videos item in the header opens the Rumble VOD gallery (`#videos`), titled “Latest from FerrousLion”. Those VODs are edited by hand. See [docs/rumble-vods.md](docs/rumble-vods.md).

The Music item opens albums and songs hosted on Suno (`#music`). That list is edited by hand, and cover art is a file in this repo. See [docs/suno-music.md](docs/suno-music.md).
