# ferrouslion.com

Public homepage for Ferrous Lion. Served by GitHub Pages at [ferrouslion.com](https://ferrouslion.com).

YouTube videos refresh automatically from the channel feed.

The header is the nine-item menu from the approved brand foundation: Home, About, Streams, Music, The Forge, Game Day, The Den, Store, and Connect. The Videos section (`#videos`) is on the homepage under the stream schedule. The Rumble VOD gallery inside it is a short list in `index.html`. Edit that block by hand, or run **Add New Rumble VOD** from the Actions tab. The workflow opens a pull request from the values you type in and does not contact Rumble. See [docs/rumble-vods.md](docs/rumble-vods.md).

The Music item opens the Forged, Not Born player (`#music`). Tracks stream from media.ferrouslion.com and do not autoplay. Cover art is a file in this repo. See [docs/suno-music.md](docs/suno-music.md).
