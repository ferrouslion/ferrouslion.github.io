# ferrouslion.com

Public homepage for Ferrous Lion. Served by GitHub Pages at [ferrouslion.com](https://ferrouslion.com).

YouTube videos refresh automatically from the channel feed.

The Videos item in the header opens the Rumble VOD gallery (`#videos`), titled “Latest from FerrousLion”. Those VODs are a short list in `index.html`. Edit that block by hand, or run **Add New Rumble VOD** from the Actions tab. The workflow opens a pull request from the values you type in and does not contact Rumble. See [docs/rumble-vods.md](docs/rumble-vods.md).

The Music item opens albums and songs hosted on Suno (`#music`). That list is edited by hand, and cover art is a file in this repo. See [docs/suno-music.md](docs/suno-music.md).
